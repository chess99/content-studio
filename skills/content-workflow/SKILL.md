# 内容创作流水线

## 流程总览

```
原始想法 → [选题编辑] → [素材研究员] → [主笔] → [图片编辑*] → [同行审校] → [渠道适配] → 发布
```

*图片编辑可选，有图片素材时 **或** 文章计划发公众号时介入。

## 阶段检测

收到任务后，先确定主题目录 `TOPIC_DIR`。默认位于内容资产仓库的
`topics/YYYYMMDD-<slug>/`，目录日期取首次立项日期。

不要假设内容资产与本 skill 在同一个仓库，也不要把具体主题产物写入
`content-workflows`。如果调用方没有提供 `TOPIC_DIR`，先在用户指定的内容
仓库中查找；仍无法确定时再询问。

确定 `TOPIC_DIR` 后，读取该内容资产仓库根目录的 `AGENTS.md` 并遵循其
资产组织规则。默认共用一份正文和素材，只在平台发生实质差异时创建渠道
版本；不要为每个发布平台复制整套文件，也不要把 ZIP 传输包纳入资产库。

| 已有文件 | 当前阶段 | 下一步角色 |
|---------|---------|-----------|
| 无（或只有原始素材） | 未开始 | 选题编辑 |
| `topic-card.md` | 选题完成 | 素材研究员 |
| `research.md` | 素材完成 | 主笔 |
| `draft.md`（无图片任务） | 初稿完成 | 同行审校（派独立 agent） |
| `draft.md`（有图片素材） | 初稿完成 | 图片编辑 |
| `review.md` | 审校完成 | 主笔处理意见 → 生成 `final.md` |
| `final.md`（计划发公众号，无 cover.jpg） | 终稿完成 | 图片编辑（封面图） |
| `final.md` + `cover.jpg` | 封面完成 | 渠道适配 |
| `final.md`（不发公众号） | 终稿完成 | 渠道适配 |

如果用户明确指定了角色（如"帮我做审校"），跳过检测直接执行。

## 执行方式

确定角色后，读取对应的 SOP 文件并按其指示执行：

- 选题编辑：`roles/topic-editor.md`
- 素材研究员：`roles/researcher.md`
- 主笔：`roles/writer.md`
- 同行审校：`roles/reviewer.md`（**独立 agent 执行，见 SOP 里的触发方式**）
- 图片编辑：`roles/photo-editor.md`
- 渠道适配：`roles/publisher.md`

## 工作区结构

```
topics/YYYYMMDD-<slug>/     # 位于内容资产仓库
├── topic.md                 # 主题元数据、渠道状态和发布链接
├── topic-card.md            # 选题卡
├── research.md              # 素材清单
├── draft.md                 # 初稿
├── review.md                # 审校意见
├── final.md                 # 渠道无关的终稿
├── shared/                  # 研究、信源和跨渠道原始素材
├── blog/                    # 博客稿件和博客专属图片
├── wechat/                  # 公众号稿件、封面和发布准备
├── xiaohongshu/             # 小红书文案和图片
└── douyin/                  # 抖音脚本、分镜和视频素材
```

## 质量门禁

`review.md` 中的 🔴 必须修改项全部处理完，才能进入渠道适配。
