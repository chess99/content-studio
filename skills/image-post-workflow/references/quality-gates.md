# 图文质量门禁

## 事实

- 数字、价格、排名、日期、人物和产品信息能追溯到 `research.md` 或 `shared/`。
- 区分实测、公开声明、用户反馈、作者判断和推断。
- 合计、倍数、排序、比例和单位重新计算。
- AI 图片中的文字、数字、图表和界面只作为待核对成品，不能反过来成为来源。

## 卡片价值

- 首图就是第一张有效内容。读者只看到它，也能获得一个事实、判断、证据或方法。
- 不存在只有标题、氛围、品牌、页码或 `1/N` 的空封面。
- 卡片数量来自最少完整表达，没有默认页数。
- 每张图都能说明删除后会失去什么独立价值。
- 正文补充图片，不逐字重复整套图片。

## 信息设计

- 每张图有唯一任务、清楚的视觉中心和阅读路径。
- 图形关系与事实关系一致。路线、箭头、位置、颜色和图例没有误导。
- 无精确比例时，没有使用面积、长度、线宽、液位或角度制造定量错觉。
- 删除文字后仍能看出构图主张，而不是只剩背景和边框。
- 多图保持必要的一致性，但使用适合各自任务的不同结构。
- 没有等大圆角白卡、普通 PPT 栅格、表单感或只换色的模板复制。
- 配色、材质和装饰来自当前题材，不机械复用历史品牌样例或流行 AI 配色。

## 图片模型

- 1—3 张中低密度知识、比较和财经图已经优先评估图片模型整图，而不是因中文或数字自动退回程序排版。
- 提示词包含完整逐字文案、阅读路径、编码规则、禁止项和缩略图目标。
- 每张图单独生成，模型原稿已保存。
- 标题、代码、数字、日期、专有名词和标签逐字核对。
- 局部编辑只修改目标区域，没有引入新错字、额外文字或构图漂移。
- 两次仍无法修正的密集小字、表格、数字或真实 UI 已缩短、拆图或改用混合制作。

## 传播与视觉

- 270×360 缩略图下，5 秒内能看出主题、核心判断和点击理由。
- 原尺寸下文字没有截断、乱码、错字，人物没有明显异常，真实 UI 没有被伪造。
- 标题、结论和关键证据的优先级高于作者名、Logo、系列名、口号和装饰。
- 视觉复杂度帮助理解。概念艺术、工艺品感或企业宣传感没有拖慢阅读。
- 发布尺寸与方向符合平台要求，重要内容避开裁切和交互区。
- 用户否定过的视觉方向已经废弃，没有靠调色、换阴影或加装饰继续修补。

## 品牌、隐私与发布

- 品牌元素只在提升识别、信任或导航时出现，没有挤占核心信息。
- 截图不暴露账号、Cookie、密钥、私聊、文件路径和未公开数据。
- 人物、品牌、影视或小说灵感说明来源与原创边界，不冒充官方素材。
- `images/` 只保留实际发布顺序中的最终图片，旧版移出或归档。
- `topic.md` 写清标题、正文、图片数量、顺序和渠道版本。
- 创建草稿或公开发布前，重新展示标题、正文、图片数量和顺序供用户确认。
