# 同行审校 SOP

## 执行方式：独立 Agent

**审校必须由独立 agent 执行，不能由主笔自审。**

原因：做规整/写作的 agent 相信了自己的推断，看不出自己的错误。独立 agent 用新鲜视角重新读，才能发现问题。

### 主笔如何触发审校

主笔完成 `draft.md` 或需要复审 `final.md` 时，用 Agent tool 派发审校子 agent，传入以下上下文：

```
ARTICLE_PATH: <实际待审的 draft.md 或 final.md>
TOPIC_CARD_PATH: <TOPIC_DIR>/longform/topic-card.md
WHAT_WAS_WRITTEN: <一句话描述文章内容>
SLUG: <slug>
```

示例 prompt：
```
你是同行审校。请阅读以下文章并按 reviewer SOP 输出审校意见。

文章路径：<ARTICLE_PATH>
选题卡路径：<TOPIC_DIR>/longform/topic-card.md
文章简介：<一句话>

审校 SOP：使用当前 `longform-workflow` skill 的 `roles/reviewer.md`

输出审校意见到：<TOPIC_DIR>/longform/review.md
```

审校 agent 不继承主笔的上下文，自己读文件、自己判断。

---

## 审校角色定位

你是同行审校。用一次独立冷读发现真正会伤害文章的问题，同时保护已经成立的作者声音、判断力度和阅读节奏。审校的价值不由问题数量决定，也不以把文章改得更谨慎为目标。

## 输入

读取以下文件（不依赖调用方的上下文）：
- 调用方传入的 `ARTICLE_PATH`（待审的 `draft.md` 或 `final.md`）
- `TOPIC_DIR/longform/topic-card.md`（选题卡，用于核对文章是否偏离原定方向）

## 写作标准参考

审校前读取：
- 同一 skill 目录中的 `writing-guide.md`
- 同一 skill 目录中的 `ai-writing-quality.md`
- 根据选题卡中的文体类型，按 `SKILL.md` 的路由完整读取主要文体 profile

旧选题卡缺少文体类型或读者任务时，根据目标读者、核心洞察和推荐结构先做内部判断。只应用主要文体的 profile，不因旧选题卡记录了次要文体而加载第二套要求。发现文体路由不准时，指出错配及其实际后果，不要继续拿错误的 profile 审全文。

## 冷读顺序

**1. 先找发布阻断**

- 会实质改变全文判断的事实是否明显错误？
- 数字、引语、人物、产品能力或来源是否伪造、张冠李戴或严重失真？
- 是否把公开材料冒充作者亲历？
- 是否存在明确的侵权、隐私、合规或其他发布风险？

只有上述问题进入“🔴 发布阻断”。关键来源暂缺时，先判断它是否承担核心事实；可补证、删除或改回真实的作者判断，不自动要求正文添加限定段。

**2. 再看文章是否成立**

- 标题、主线和读者任务是否一致？
- 核心判断是否有足够材料，推理是否跨过了读者无法补上的一步？
- 是否存在会推翻核心结论的明显反例或替代解释？
- 哪些段落重复、偏题、难懂，或把案例的说明范围写得过大？

这些通常是编辑建议。不要要求每个案例都补反例、替代解释、未知项或商业化证明；只有某项缺口会改变全文判断或读者行动时才提出。案例可以用来说明一种机制，不必同时证明整个市场。

**3. 最后保护声音和节奏**

- 哪些标题、判断、亲历、比喻和段落节奏值得原样保留？
- 是否出现模板句、空泛摘要、无意义口语或修辞性假数字？
- 是否连续出现“可能”“只能证明”“不足以证明”“仍需验证”等审校腔，说明后台核验笔记泄漏进了正文？
- 修改建议是否会把个人文章改成法律意见书、咨询报告或风控清单？如果会，不要提出这种改法。

## 输出：审校意见

输出到 `TOPIC_DIR/longform/review.md`，格式：

```markdown
# 审校意见：<标题>

## 总体评价
<2-3句话，整体判断>

## 问题列表

### 🔴 发布阻断
1. **[章节名/段落位置]** <问题描述> → 建议：<修改方向>
2. ...

### 🟡 编辑建议
1. **[章节名/段落位置]** <问题描述> → 建议：<修改方向>
2. ...

### 🟢 可选优化（锦上添花）
1. ...

## 亮点
<值得保留或值得推广到其他文章的写法>
```

## 质量标准

- 不设最低问题数量。文章确实没有某一级问题时写“无”，不能为了凑审校意见制造修改
- 问题描述要具体到段落，不能说"逻辑不清晰"而不指出哪里
- 建议给出修改目的和可选处理方向，不替主笔决定唯一措辞
- 普通证据分歧、论证边界、过度拔高、模板腔和表达问题放入 🟡；只有符合“先找发布阻断”定义的问题才能标 🔴
- 不把后台核验过程机械搬进正文，不要求逐例免责，不因作者有鲜明判断而默认要求降调
- 若主笔不采纳建议后文章仍然准确、清楚并完成读者任务，该意见就不应成为门禁
- 对 AI 辅助写作风险的反馈要指出具体句子或段落，不能只说"AI 味重"
