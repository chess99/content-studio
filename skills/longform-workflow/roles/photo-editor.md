# 图片编辑 SOP

## 角色定位

负责为长文选择、制作和放置真正增加理解的图片。不要为了“图文并茂”凑图，也不要用固定封面模板替代文章判断。

## 正文配图

### 选图

优先选择：

- 能证明文章中某个事实、结果或过程的截图与照片；
- 文字难以替代的架构图、流程图、对比图和数据可视化；
- 能让读者更快理解核心概念的场景或示意图。

跳过：

- 只有标题、目录或纯文字列表的幻灯片；
- 与文章重复、没有信息增量的装饰图；
- 同一画面的重复拍摄；
- 来源、授权或事实身份不清楚的素材。

图片数量跟着内容走，没有默认范围。

### 检查图片

- 有原生图片查看工具时直接查看，不用 OCR 代替视觉判断。
- 批量材料可以用 OCR 辅助检索，专有名词、数字和表格仍要回到原图核对。
- OCR 结果只帮助定位，不得覆盖人工记录或充当事实来源。
- 插图放在它支持的段落或章节附近，alt text 说明图片真正呈现的内容。

### 处理与保存

- 不覆盖原图。处理版放入当前长文的 assets 目录。
- 按平台压缩，避免肉眼可见的模糊、色带和小字损坏。
- 截图清理账号、Cookie、密钥、私聊、路径和未公开信息。

## 公众号封面

只在文章计划发布到公众号且平台确实需要封面时执行。

### 1. 提取封面任务

读取 `longform/final.md`，确定：

- 文章讲什么；
- 最值得点击的结果、冲突或证据是什么；
- 哪个真实产品、人物、场景或图形关系最适合成为视觉中心；
- 哪些文字必须出现，哪些可以删除。

不要默认放账号名、系列名、Logo、品牌短句或编号。

### 2. 提出视觉方向

至少提出两个真正不同的方向，例如真实结果证据、人物或产品主体、信息关系图、强场景。不要只在同一模板上换颜色。

优先级为：

```text
文章可识别 → 点击理由 → 真实证据或明确关系 → 缩略图效果 → 装饰
```

### 3. 选择生产方式

- 产品、过程和结果优先用真实截图、摄影或真实素材。
- 需要整体构图、插画和文字统一时使用图片模型。
- 需要真实截图加统一视觉时使用混合制作。
- 密集精确文字、图表或真实 UI 无法交给模型时再使用确定性工具。

模型生成的文字、Logo、产品界面和数字都要核对，不能当作证据。局部错字优先做单点编辑，不为修一个字重做已经成立的整图。

### 4. 尺寸与验证

- 公众号封面最终尺寸为 `900×383`，约 2.35:1。
- 生成时让标题、主体和证据位于中央安全区，适配时优先裁切或扩图，不明显拉伸。
- 在原尺寸和公众号裁切预览中检查标题、主体、数字、人物和 Logo。
- 最终文件保存为 `longform/wechat/cover.jpg`，确认内容确实是 JPEG。

平台封面只是文章入口，不是固定品牌海报。若文章的真实成品、人物或关键场景已经足够强，直接使用它。
