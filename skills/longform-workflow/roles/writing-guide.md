# 通用写作指南

这份指南只规定所有长文共享的标准。题材的取材、结构和语气以 `SKILL.md` 路由到的文体 profile 为准。

## 先确认文章契约

动笔前从选题卡确认三件事。

- 主要文体是什么。
- 读者读完需要理解、判断或完成什么。
- 哪些事实、经历和判断足以支撑这个任务。

旧选题卡缺少文体字段时，根据目标读者、核心洞察和推荐结构作出判断。不要把缺少字段当成停工理由，也不要为了沿用已有标题而选错文体。

## 声音来自取舍

文章要让人看得出作者依据什么材料、重视什么差异、愿意为哪项判断负责。做到这一点不需要频繁使用“我”和“你”。

- 第一人称只在亲历、实验动作、判断来路或认知变化确有价值时使用。
- 第二人称只在直接指导读者操作或讨论读者处境时使用。
- 没有亲历时，用可核验材料、普通流程和明确推理写作，不制造第一人称现场。
- 幽默、口语和情绪都要从当前材料长出来，不按固定频率添加。

## 开头与标题履行同一个承诺

标题要让目标读者知道文章讨论的具体对象、问题、结果或判断，不能靠“我的思考”“全面解析”制造空泛期待。

开头尽快碰到文章真正处理的东西。教程可以先给问题和可见结果，评测可以先给测试任务，行业分析可以先写发生了什么，评论可以先落到争议事实，个人叙事可以从关键场景进入。不要把其中一种开头扩成所有文体的模板。

## 结构跟着读者任务走

按材料之间的时间、因果、操作依赖或争议关系组织正文。每一节都应增加新事实、新动作、新区别、新证据或新判断。

- 小标题用于定位，不负责把每段提前总结一遍。
- 各部分不必等长，也不必凑固定数量。
- 具体案例服务文章主线。与读者任务无关的业务细节、背景知识和旁支故事应删去或缩短。
- 删除一段后不影响读者完成任务，说明这段大概率不在主线里。

## 事实和判断保持可分辨

- 数字、引用、人物、论文、具体产品能力和外部归因必须有来源或可复现实验说明。
- 核心作者判断把依据放在附近，可以直接表达，不必句句加“可能”“在一定程度上”来证明谨慎。
- 推测不要冒充已发生的外部事实。普通经验判断不需要改写成论文结论。
- 真实经历不能由公开材料或常见流程冒充。

具体核查方式遵循 `ai-writing-quality.md`。

## 清掉模板腔

以下写法只有在制造空洞升格、虚假对立或连续套用时才重写。能够准确区分两个概念、承担标题张力或保留作者声音的句子可以保留。

- 用宏大词替代事实，把普通变化包装成新范式或历史节点。
- 用形容词代替结果，只说高效、强大、流畅，却没有条件与证据。
- 用“首先、其次、最后”“值得注意的是”“不难发现”给段落机械排队。
- 用“这不仅是……更是……”“不是……而是……”给没有真实差别的内容强行翻案。
- 为了显得像真人，主动添加口头禅、粗口、倒装、错别字或无意义冗余。

## 结束在任务完成处

读者任务已经完成，文章就可以结束。结尾可以给适用边界、下一步动作、当前判断或经历后的变化，不要重新摘要全文，也不要临时拔高到时代、行业或人生。

## 通用自检

- [ ] 标题、开头和正文履行同一个读者承诺
- [ ] 主要文体与读者任务明确
- [ ] 每一节都有新材料或新判断
- [ ] 事实、亲历、推测和作者判断能够分辨
- [ ] 人称由材料决定，没有强制第一人称或假装对话
- [ ] 没有无来源数据、模板化转折和空洞升格
- [ ] 文章在读者任务完成后及时结束
