# 信息图

先写出要表达的关系，再选布局。布局必须能保留信息的方向、量纲和重要程度。

上游布局目录：`vendor/JimLiu/baoyu-skills/baoyu-infographic/references/layouts/`。

| 关系 | 优先参考 |
|---|---|
| 顺序、工序、时间推进 | `linear-progression.md` |
| 同一维度下比较 | `binary-comparison.md`、`comparison-matrix.md` |
| 部件如何构成整体 | `structural-breakdown.md` |
| 因果环与反馈 | `circular-flow.md` |
| 分类与层级 | `tree-branching.md`、`hierarchical-layers.md` |
| 空间位置与路径 | `isometric-map.md` |

只有独立信息确实并列时才采用网格。图表面积、箭头粗细或物体大小如果暗示定量关系，必须依据真实数值；装饰性的差异不要伪装成数据编码。

逐字确定标题、标签、单位和注释。中文长段落优先精简、拆图，或者采用插画与可控排版分离的制作方式。地图、拓扑或精确机械结构须核对位置与连接关系。

画风参考在同级 `styles/`。只读取与目标受众和材料相关的一到两种，取其造型、色彩与材质原则，避免把参考默认文案带入成图。
