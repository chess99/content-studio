# 素材剪辑

先保留原始文件，读取媒体参数并抽帧。含对白时用 `tools/transcribe_video.py` 获取转录，按其实际 CLI 帮助操作。口播、对话、音乐或完整镜头的切点要结合试听和画面，不能只依赖静音区间。

为选用的片段记录原文件、入点、出点、所表达的信息。少量修改可直接使用 FFmpeg；需要复杂字幕、镜头编排或图形叠加时使用已有 Remotion 或 HTML 时间线。不要为纯裁剪引入新的渲染项目。

## 剪辑要点

- 可变帧率、HDR 和旋转元数据会影响对齐与颜色。先确认目标格式，必要时生成恒定帧率或 SDR 工作副本。
- 字幕以实际人声时间为准；断句按语义，保留足够阅读时间。不能以总字数均分字幕时间。
- 竖屏改编需要重新取景，确保主体、图表和字幕都可见；分屏或留白常比强裁切更合适。
- 口播删句后检查上下文是否改变原意，避免把停顿、语气或引用主体剪错。
- 原声、配音、音乐分别控制。检查峰值削波和对白可懂度；没有实际测量就不声称响度达标。

## 检查与交付

```sh
python3 tools/media_review.py "<INPUT_VIDEO>" --output-dir "<TOPIC_DIR>/video/review/source-01"
python3 tools/media_review.py "<OUTPUT_VIDEO>" --output-dir "<TOPIC_DIR>/video/review/cut-01" --expect-size 1080x1920 --expect-duration 30 --require-audio
```

工具生成技术报告和均匀抽帧联系表，不评价剪辑质量。额外查看所有剪切点前后、字幕密集区和被裁剪的主体。最终交付所需成片、字幕与可复现剪辑参数，工程笔记留在 `video/`，不烧录到画面。
