# 新视频项目模板

把本目录复制到内容资产仓库的 `TOPIC_DIR/video/` 后再填写；不要直接在 app 的 `projects/` 下制作正式视频。

1. 填写 `input/source.md`。
2. 在 `input/sources.json` 中登记来源。
3. 将图表数据写入 `input/data.csv`，无图表数据时保留表头并说明。
4. 生成 `brief.json`、`script.json` 与 `storyboard.json`。
5. 脚本审核通过后，再生成配音、字幕与预览。
6. 最终输出放入 `publish/`，渲染中间产物放入 `renders/`。
