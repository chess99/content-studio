# Codex / Claude 项目协作说明

## 目标

本仓库用于把经过核验的知识内容自动转换为竖屏知识视频。AI 负责整理资料、写口播、生成结构化分镜、调用配音与渲染工具、执行质检；人负责事实确认和最终预览确认。

## 不可跳过的规则

1. 正式项目目录由调用方通过 `--project-dir` 提供；先读其中的 `input/source.md`、`input/sources.json` 与数据文件，再写稿。
2. 所有事实性陈述和关键数字必须能追溯到 `sourceIds`。
3. 图表数据只能来自项目输入，不得自行补齐或猜测。
4. 配音按场景生成，场景时长以实际音频时长为准。
5. 配音前必须等待脚本审核；正式渲染前必须等待低清预览审核。
6. 不得自动发布到任何平台。
7. 密钥只能放在 `.env` 或安全的密钥服务中，不得写入脚本、分镜或提交记录。
8. `projects/` 只保存 `_template` 和测试夹具；具体视频资产属于外部内容仓库，不得重新复制进本 app。
9. 制作正式项目时读取外部内容仓库的 `brand/BRAND.md`；制作账号发布封面时再读取其指定的 `brand/COVER.md`。`themes/` 是可复用视觉预设，不是账号母品牌，不得覆盖外部品牌的名称、字标、系列和签名。

## 默认输出

- 1080 × 1920，9:16，30 fps
- H.264 视频与 AAC 音频
- 独立字幕文件
- 工程预览封面、标题候选、平台文案、来源说明与免责声明；正式发布封面由上层 workflow 按外部账号品牌生成

## 修改原则

- 优先复用 `templates/` 中的注册模板。
- 按项目选择 `themes/` 中的视觉预设；预设只控制版式、图表和动效。
- 外部服务通过 `src/providers/` 适配器接入。
- 渲染器通过 `src/renderers/` 适配器接入。
- 每次生成后运行 `npm run check:structure` 和后续补充的事实、画面、音频质检。
