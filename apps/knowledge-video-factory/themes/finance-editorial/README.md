# 财经编辑部视觉预设

## 边界

本目录是知识视频工厂的项目级视觉预设，只控制版式、图表、字幕和动效。正式项目必须先读取外部内容资产仓库的 `brand/BRAND.md`；账号名、作者字标、Logo、栏目、签名和颜色语义以外部母品牌为准。

历史样片中的“坐标轴 + 红色基准刻度”“市场温度计”和“用数据校准判断”是项目级探索，不是默认账号品牌，也不会自动用于其他栏目。

## 适用内容

- 财经与商业科普
- 估值、排名、历史对比等数据叙事
- 需要真实坐标轴、表格和来源卡的知识视频

## 视觉语言

- 冷灰纸面、黑色主判断、少量信号红和金融蓝。
- 硬切边、编辑式分栏、真实坐标轴和清晰基线。
- 数字、来源和数据口径优先，不用装饰替代观点。
- 字幕使用高对比矩形底，不使用玻璃拟态、悬浮胶囊和无意义阴影。
- 允许硬切、线性擦除、图表绘制、数字跳变和短距离位移。
- 禁止持续漂浮、粒子、呼吸光和卡片果冻式弹出。

### 预设色板

- 冷灰纸面：`#F2F3F5`
- 纯白信息面：`#FFFFFF`
- 主文字：`#111418`
- 图表深底：`#242A31`
- 次级文字：`#69717A`
- 分隔线：`#C8CDD3`
- 信号红：`#D83B32`
- 金融蓝：`#245C87`
- 强调橙：`#F15A29`

这些颜色只在不冲突时补充账号母品牌；作者字标和栏目导航色仍以外部 `brand/BRAND.md` 为准。

### 版式细则

- 数字优先使用 Arial 系列，中文优先使用微软雅黑或 Noto Sans SC。
- 首屏使用问题、大数字和两列事实，不使用圆环仪表盘。
- 数据图表可切换为深色底，其他页面保持冷灰纸面。
- 对比项使用表格行或编号清单，不堆叠圆角卡片。
- 大数字设置单行约束；区间数字不得进入图形边界或裁切区。

### 反“AI 味”检查

- 是否依赖圆角卡片表达所有信息？
- 是否像网页组件按顺序自动出现？
- 是否用装饰代替数据和观点？
- 是否缺少真实基线、刻度、来源和编辑层级？

前三项任一为“是”，不得进入正式渲染。

## 安全区

- 1080×1920 画布左右主体边距至少 72 px。
- 平台交互区上方预留 112 px，字幕位于底部 148 px 以上。
- 作者、栏目、标题和核心视觉必须进入中央 3:4 裁切安全区。
- 正式渲染前检查来源、数据、字幕、裁切和 25% 缩略图。
