# 独立审核闸门

每条知识视频在正式渲染前至少经过两名与制作 agent 相互独立的审核者。审核者默认只出报告，不直接改文件，由主制作 agent 合并意见并实施。

## 内容审核

输入：原始资料、来源清单、数据文件、口播稿和分镜。

必须检查：

- 数字、口径、年份和限定条件是否一致；
- 是否把不同口径取平均、拼接或暗示成同一序列；
- 结论是否超出来源能够支持的范围；
- 是否存在机器腔、指代不清、重复结论或突兀转折；
- 口播和当前画面是否讲同一件事；
- 分清事实、计算结果和分析判断。

报告按 P0（必须改）、P1（建议改）、P2（语言优化）排序，并优先给最小修改建议。

## 视觉与品牌审核

输入：封面、每场景中段关键帧、设计规范和最终视频。

必须检查：

- 是否仍像网页、报告翻页或通用 AI 模板；
- 文字是否穿模、重叠或进入平台交互区；
- 颜色语义、图表标注和来源脚注是否一致；
- 封面在 25% 缩略图下是否只剩一个清楚的判断；
- 主品牌、系列编号、字幕锚点和片尾签名是否连续。

## 发布前条件

- P0 问题全部关闭；
- 技术质检通过；
- 封面使用独立 composition，而不是视频抽帧；
- 低清预览由人工确认后再发布；
- 不自动发布到平台。
